# Multi-Branch Inventory & Transfer Management System

A MERN stack based inventory management system designed for a multi-branch meat and grocery business. The system helps branches digitally manage stock, record incoming inventory, transfer products between branches, track waste, and generate Excel reports automatically.

The main goal of this project is to replace manual Excel-based stock tracking with a centralized web application that stores every inventory action as a movement record. These movement records are then used to calculate current stock, track history, and generate Excel reports in the same style as the client’s existing sheets.

## Key Features

- Admin and shopkeeper authentication
- Role-based and branch-based access control
- Branch/shop management
- Product and category management
- Current inventory tracking
- Incoming stock management
- Stock transfer between branches
- Waste/damaged stock tracking
- Inventory movement history
- Custom date range Excel export
- Dashboard for stock, transfers, waste, and reports

## Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js
- Mongoose
- JWT Authentication
- ExcelJS
- Tailwind CSS
- Redux Toolkit

## Project Purpose

This project is built to help businesses with multiple branches manage inventory more accurately, reduce manual work, prevent stock errors, and generate professional Excel reports directly from the system.
